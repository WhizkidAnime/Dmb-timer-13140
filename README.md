# ДМБ таймер

Таймер до дембеля: сколько осталось, армейские даты, календарь службы и заметки. Работает как веб-приложение на iPhone, в том числе без интернета.

## Файлы

```
index.html              приложение
manifest.webmanifest    описание веб-приложения (имя, иконки)
sw.js                   офлайн-режим
icons/                  иконки для экрана «Домой»
.nojekyll               отключает обработку Jekyll на GitHub Pages
```

Все файлы должны лежать в корне репозитория, папка `icons` — рядом с `index.html`.

## Публикация на GitHub Pages

1. Создай репозиторий, например `dmb`.
2. Загрузи все файлы: Add file → Upload files. Файл `.nojekyll` скрытый: на Mac покажи скрытые файлы сочетанием Cmd+Shift+. Он не обязателен, без него тоже заработает.
3. Settings → Pages → Build and deployment → Source: Deploy from a branch, ветка `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт будет доступен по адресу `https://<логин>.github.io/dmb/`.

## Установка на iPhone

1. Открой адрес в Safari.
2. Поделиться → «На экран „Домой“» → Добавить.
3. Запускай с иконки «ДМБ»: приложение откроется на весь экран, без адресной строки.

После первого запуска с интернетом приложение работает офлайн.

## Данные

- Даты, события и заметки хранятся только на устройстве, на сервер ничего не отправляется.
- Приложение с экрана «Домой» и сайт в Safari хранят данные раздельно. Пользуйся чем-то одним.
- Если удалить иконку с экрана «Домой», данные удалятся вместе с ней.
- Делай копию: «Даты» → «Сохранить копию». Восстановить: «Даты» → «Восстановить» и выбрать файл.

## Обновление

1. Замени изменённые файлы в репозитории.
2. В `sw.js` увеличь версию: `dmb-v1` → `dmb-v2`.
3. На телефоне закрой приложение и открой дважды: первый раз загрузится новая версия, второй раз она покажется.
